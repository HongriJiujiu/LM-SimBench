# Matrix-operator prediction figures

Place prediction CSV files (with columns `duration_us`, `pred_total_us`, `m`, `n`, `k`, `type`) under **`predictions_input/`** next to `plot_prediction_effect.py`. Files should be named `*_predicted.csv`. Figures are written to **`figures/`**.

Bundled **`data/derived_metrics/`** contains example `prediction_metrics_*.csv` summaries from a prior run.
